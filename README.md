# Week 2 – Cybersecurity & Ethical Hacking

## 📌 Project Overview

This repository contains my **Week 2 practical work** from the Cybersecurity & Ethical Hacking program.

The week focused on two important areas of cybersecurity:

* 🔎 **Footprinting & Reconnaissance** using multiple Kali Linux tools
* 🌐 **Network Scanning** using Zenmap

The activities helped me understand how security professionals collect information, analyze network environments, and identify active hosts during the initial stages of a security assessment.

---

## 🎯 Objectives

* Understand the basics of cybersecurity reconnaissance.
* Practice using multiple information-gathering tools in Kali Linux.
* Identify DNS and web-technology information.
* Understand HTTP response headers and WAF detection.
* Identify my local IP address and subnet.
* Perform host discovery using Zenmap.
* Understand and document real scan results.

---

## 🛠️ Tools Used

### Footprinting & Reconnaissance

* **WHOIS** – Domain information gathering
* **WhatWeb** – Web technology identification
* **Nslookup** – DNS and IP resolution
* **Curl** – HTTP response-header inspection
* **Wafw00f** – WAF detection
* **DNSRecon** – DNS record enumeration

### Network Scanning

* **Zenmap / Nmap** – Network and host discovery
* **Windows CMD** – Local IP and network configuration

---

## 🔎 Module 1 – Footprinting & Reconnaissance

I used multiple Kali Linux tools to perform basic reconnaissance on the assigned domain.

The tools provided different types of information, including:

* Domain-related information
* Web technologies
* IP and DNS information
* HTTP response headers
* WAF information
* DNS records

This activity helped me understand how different reconnaissance techniques can be combined to build an initial picture of a web application's infrastructure.

---

## 🌐 Module 2 – Network Scanning with Zenmap

For the network-scanning activity, I identified my local network configuration using Windows CMD and then used Zenmap to perform a **Ping Scan** on my own local network.

### Scan Result

**Hosts detected: 1**

The single live host detected was **my own device**.

The result was documented based on my actual network environment rather than using the example results provided in the practical instructions.

I also explored the **Zenmap Topology** view as part of the practical task.
